# Pokémon Data Analysis

Projeto desenvolvido em Python para praticar integração entre API REST, MySQL, Pandas e Matplotlib.

## Tecnologias

- Python
- Requests
- MySQL
- Pandas
- Matplotlib

## Objetivo

Consumir dados da PokéAPI, armazená-los em um banco MySQL e gerar gráficos para análise.

## Fluxo do projeto

PokéAPI
↓
Python
↓
MySQL
↓
Pandas
↓
Matplotlib

## Estrutura

api.py
banco.py
grafico.py
main.py
